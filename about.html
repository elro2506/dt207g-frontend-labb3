Om uppgiften

I denna laboration för att visa, lägga till och radera arbetslivserfarenheter använder jag mig av REST-API som är byggt med Node.js och Express. Jag använder mig även av en NoSQL-databas som heter MongoDB. Jag har byggt min frontend-sidan med HTML, CSS och JavaScript där jag använder mig av fetch API för att kunna kommunicera med backend- sidan.


Slutsatser

Det är fortfarande ganska svårt att separera backend och frontend men det är glädjande att se hur de samarbetar.
