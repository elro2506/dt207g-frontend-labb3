Om uppgiften

Denna uppgift handlar om att skapa en REST-baserad webbtjänst. På min webbplats kan man visa, lägga till och radera arbetslivserfarenheter. Jag har byggt ett eget API med node.js och Express. Som databas har jag använt SQLite och arbetslivserfarenheterna visas i en tabell. För att kunna kommunicera mellan frontend och backend så använder jag mig av fetch API och JSON.


Slutsatser

Även om det börjar klarna lite så är backend väldigt svårt och kämpigt. Det kändes dock kul att få rätt på det så att saker och ting kunde börja hänga ihop. Det blev tydligare hur de olika delarna i webbaplikationen samarbetar.
