# Laboration 3 - frontend

## Beskrivning
Jag har byggt en webbapplikation som visar arbetslivserfarenheter. Man har möjlighet att se, lägga till och radera arbetslivserfarenheter.

## Tekniker
- HTML
- CSS
- JavaScript
- Fetch API

### Startsida
På denna sida kan man se de arbetslivserfarenheter som finns.

### Lägga till arbetslivserfarenheter
Här finns ett formulär där man kan lägga till arbetslivserfarenheter.
